**제조사 매뉴얼 기반 컨베이어 고장 진단 RAG 챗봇**

현장 엔지니어가 컨베이어의 고장 증상이나 설비 사진을 입력하면, 제조사 매뉴얼을 검색하여 예상 원인과 조치 방법, 안전 수칙을 안내하는 AI 챗봇입니다.

### 주요 기능
- **하이브리드 검색:** Chroma 벡터 검색과 BM25 키워드 검색을 활용한 매뉴얼 검색
- **이미지 분석:** 명판 및 벨트 손상 사진 분류와 설비 정보 분석
- **근거 기반 답변:** 매뉴얼 출처와 안전 수칙을 포함한 답변 제공
- **관리자 대시보드:** 운영 현황, 답변 품질 및 시스템 상태 확인

### 담당 작업
- 컨베이어 매뉴얼 섹션 기반 청킹 및 Chroma·BM25 색인 구축
- 이미지 유형 분류 및 명판 합성 테스트 이미지 제작
- 관리자 대시보드 시스템 탭 작업
- GitHub 협업 환경 및 브랜치·PR 규칙 설정
